# Imitation Engines

A letter by William Taysom about AI, consciousness, and what it means to imitate.

Read it at: **[wtaysom.github.io/imitation-engines](https://wtaysom.github.io/imitation-engines/)**

If you've found your way here, welcome. Pull up a chair.

The homepage's latest entries and the RSS feed share `_data/entries.yml`. Add new
entries at the top, using the publication date for `display_date`, `datetime`, and
`published_at`. For older entries whose exact publication day is unknown, keep a
month-only date and omit `published_at`. Existing entry URLs serve as stable feed
identifiers; rebuilding the site does not change publication dates.

Build locally with `rbenv exec jekyll build --disable-disk-cache`.
